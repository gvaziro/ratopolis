# Ratropolis Underground | Крысиный мегаполис

Инкрементальная игра про крысиную стимпанк-цивилизацию под викторианским Лондоном. Начинаешь у решётки стока, тащишь крошки, монетки, пуговицы и проволоку, строишь мастерские и узкоколейку, осваиваешь канализацию, подвалы, подземку и Большой вокзал. Для людей поезд — это просто поезд 8:15. Для крыс это землетрясение из стали, после которого с неба сыплются сокровища.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:3000.

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер Next.js |
| `npm run build` | продакшен-сборка |
| `npm run start` | запуск собранной версии |
| `npm test` | тесты движка (Vitest) |
| `npm run sim` | headless-симулятор баланса (активный и пассивный боты) |
| `npm run typecheck` | проверка типов |

## Управление

- **Клик по решётке** — тащить крошки (и иногда находки).
- **Зажать и вести** по падающим предметам во время событий — свайп-сбор, комбо растёт с каждым пойманным подряд.
- **Пробел** — бросить крюк-кошку, когда мимо идёт багажный вагон.
- Вкладки справа (на телефоне — снизу): постройки, работы, улучшения, карта, расписание, переселение, медали, настройки.

## Отладка

Панель разработчика (🛠 в правом нижнем углу) видна в `npm run dev` или с параметром `?dev` в адресе: ускорение времени, выдача ресурсов, открытие зон, вызов событий.

## Технологии

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Zustand. Вся графика — SVG, CSS, эмодзи и canvas; все звуки синтезируются WebAudio. Сохранение в localStorage, офлайн-прогресс до 8 часов.
